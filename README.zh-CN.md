## 概述

FileIndex 是一款按文件名一次搜索电脑上所有驱动器的搜索工具。在搜索框中输入文字的同时,结果会随之即时更新;韩文用户只输入初声(首辅音)也能找到文件(`ㅅㅈ` → 설정)。

首次运行时会为各驱动器建立文件列表,此后实时跟踪文件的新建、删除和重命名,始终显示最新结果。可以组合使用扩展名、大小、通配符和正则表达式条件,还能找出名称、大小或内容相同的重复文件。

找到的文件可以像在资源管理器中一样打开、复制、拖放并使用右键菜单。关闭窗口后程序会留在托盘中,随时可以立即调出;隐藏期间几乎不占用内存。

## 主要功能

- **边输入边搜索** — 查找包含所有以空格分隔的词语的名称。不区分大小写。
- **韩文初声搜索** — 只输入 `ㅅㅈ` 就能找到 "설정"、"사진" 等初声相符的名称。
- **搜索条件** — 扩展名(`ext:`)、大小(`size:`)、通配符(`*` `?`)、正则表达式(`regex:`)。
- **查找重复文件** — 名称相同(`dupe:name`)、大小相同(`dupe:size`)、内容完全相同(`dupe:content`)。
- **实时更新** — 文件一有变化,搜索结果立即反映。关闭期间的变化也会在启动时补上。
- **自动索引 USB 驱动器** — 新插入的驱动器会自动编制索引,拔出后从结果中移除。
- **像资源管理器一样操作** — 双击打开、打开文件位置、多选复制、拖到资源管理器、资源管理器右键菜单。
- **预览** — 在列表旁显示所选文件的缩略图(照片、视频、PDF、Office 文档等)。
- **排序与高亮** — 按名称、路径、大小、修改日期排序,并高亮名称中与搜索词匹配的部分。
- **常驻托盘** — 关闭窗口即隐藏到托盘,隐藏期间几乎不占用内存。
- **只在本机** — 文件列表只保存在你自己的电脑上。
- **22 种语言,浅色·深色主题** — 默认跟随 Windows 设置,也可以自行选择。

## 使用方法

### 初次使用

1. 运行 FileIndex。首次运行时,在为各驱动器建立文件列表期间,窗口中央会显示 **C: 正在编制索引 42%** 这样的进度。完成后切换到搜索界面。
2. 在搜索框中输入文件名的一部分。边输入边在下方列表中显示结果,底部显示找到的数量。
3. **双击** 想要的文件,或用方向键选中后按 **Enter**,即可用关联的程序打开。要打开文件所在的文件夹,按 **Ctrl+Enter**。
4. 用完后点击窗口的关闭按钮(X)或按 **Esc**。程序不会退出,而是隐藏到托盘。点击托盘图标即可立即重新显示。

从第二次运行起,会接着使用已建立的列表,只补上关闭期间的变化,因此可以马上开始搜索。

### 使用场景

**用初声快速查找韩文名称**
只输入韩文辅音,就能找到初声按顺序匹配的名称。`ㄱㅇㅅ` 会找到 "계약서"、"계약서_수정본" 这样初声依次包含 ㄱ·ㅇ·ㅅ 的名称。再长的名称也只需几个字就能找到。

**用多个词缩小范围**
用空格分隔输入,只保留包含所有词的名称。`report 2026` 会找到名称中同时含有 "report" 和 "2026" 的文件。词语顺序无关。

**只查找特定扩展名**
在 `ext:` 后用 **分号(;)** 连接扩展名。文件夹会被排除,只显示文件。
- `ext:pdf` — 所有 PDF 文件
- `ext:jpg;png;gif travel` — 名称中含有 "travel" 的图片

**查找大文件以释放磁盘空间**
用 `size:` 设置大小条件。单位为 `b` `kb` `mb` `gb` `tb`,不写单位则为字节。
- `size:>1gb` — 大于 1 GB 的文件
- `size:1mb-5mb` — 1 MB 以上、5 MB 以下(`1mb..5mb` 也一样)
- `ext:mp4 size:>500mb` — 超过 500 MB 的视频

点击 **大小** 列标题排序,即可从最大的文件开始查看。

**用通配符匹配名称形式**
`*` 表示任意多个字符,`?` 表示任意一个字符。使用通配符时,**整个名称** 都必须符合该形式。
- `*.txt` — 扩展名为 txt 的文件
- `readme*` — 以 readme 开头的名称
- `IMG_????.jpg` — IMG_ 后接四个字符的图片

**用正则表达式更精确地查找**
在 `regex:` 后写正则表达式。不区分大小写,匹配名称中的任意位置即可。要固定开头和结尾请用 `^` `$`;空格会分隔搜索词,因此模式中的空格请写成 `\s`。
- `regex:^\d{8}` — 以 8 位数字(如日期)开头的名称
- `regex:(draft|final)` — 含有 draft 或 final 的名称

条件写错时,状态栏会显示正确写法的示例。

**整理重复文件**
使用 `dupe:` 会把相同的文件归为一组并依次显示。与其他条件一起使用时,只在这些结果中比较。
- `dupe:name` — 名称相同的文件(不区分大小写)
- `dupe:size ext:jpg` — 大小相同的图片
- `dupe:content ext:mp4` — **内容完全相同** 的视频

`dupe:content` 会实际读取文件进行比较,因此状态栏会以 **正在比较内容 — 文件 n/N,x/y MB** 显示进度。中途更改搜索词即停止比较。在每组中选中除要保留的那个以外的文件,右键 → 删除即可。

**查找刚下载的文件**
默认排序为 **修改日期** 从新到旧,因此只需输入名称的一部分,最近下载或修改的文件就会排在最上面。新建或保存的文件会立即出现在结果中。

**结果太多时 / 想查看全部时**
列表默认最多显示 **200** 个。搜索始终针对全部文件,排序后从前面开始显示,因此得到的是"最新的 200 个"、"最大的 200 个"。状态栏中的 `200 / 14,092 个项目` 表示共 14,092 个结果中显示了 200 个。想看更多,请调高 **设置 → 最大结果数**。

**将多个文件复制或移动到别处**
- 用 **Ctrl·Shift 单击**、**Shift+方向键** 选择多个文件,按 **Ctrl+A** 选择全部结果。
- 按 **Ctrl+C** 复制后,在资源管理器中粘贴。
- 也可以把选中的文件 **拖到资源管理器或桌面**。与资源管理器相同,同一驱动器内为移动,不同驱动器之间为复制。

**使用资源管理器右键菜单**
右键单击结果,会出现与资源管理器相同的菜单(打开方式、发送到、压缩、删除、属性等)。按住 **Shift** 右键单击还会显示扩展命令。从该菜单启动的程序以普通用户权限运行,而不是管理员。

**不打开就查看照片和文档**
**预览** 开启时(默认),每次选中文件,列表右下方都会显示缩略图。与资源管理器的缩略图相同,不仅是照片,视频、PDF、Office 文档也能预览。可以用方向键依次浏览。

**在 U 盘或外置硬盘中查找**
插入后几秒内自动编制索引,并一起出现在结果中。拔出后该驱动器的结果会消失,重新插入则重新编制索引。

**只用键盘操作**
焦点始终在搜索框中,可以直接输入。

| 键 | 操作 |
|---|---|
| ↑ ↓ / PgUp PgDn | 选择结果(同时按住 Shift 为范围选择) |
| Enter | 用关联的程序打开(未选择时打开第一个结果) |
| Ctrl+Enter | 在资源管理器中打开文件位置 |
| Ctrl+A / Ctrl+C | 选择全部结果 / 复制所选文件 |
| Esc | 清除搜索词;若已为空则隐藏到托盘 |

**从快捷方式或脚本直接打开搜索**
在 `--search`(或 `-s`)后给出搜索词,FileIndex 会以该搜索词的结果打开。如果 FileIndex 已在运行,则由已打开的窗口执行该搜索。

```
FileIndex.exe --search "ext:pdf contract"
FileIndex.exe -s "*.psd"
```

加到桌面快捷方式的目标中,即可一键打开常用的搜索。

**常驻后台,像快捷键一样使用**
开启 **开机时运行** 后,登录时会不显示窗口、直接在托盘中启动。需要时点击托盘图标,窗口出现时光标已在搜索框中,直接输入即可。要完全退出程序,请右键单击托盘图标 → **退出**。

## 设置

用标题栏中的设置按钮打开 **设置**。更改会立即保存并生效。

| 分类 | 项目 | 默认值 |
|---|---|---|
| 常规 | 默认排序(按名称 · 按路径 · 按大小 · 按修改日期) | 按修改日期 |
| 常规 | 主题(系统 · 浅色 · 深色) | 系统 |
| 常规 | 语言(系统 + 22 种语言) | 系统 |
| 常规 | 最大结果数 | 200 |
| 常规 | 预览 | 开启 |
| 常规 | 开机时运行 | 安装版为开启 |
| 关于 | 版本 · 作者 · 主页 · 许可证 | — |

点击 **[重置]** 会将设置恢复为默认值,并关闭开机时运行。已建立的文件列表保持不变。更改语言后无需重启程序,界面会立即切换为该语言。
